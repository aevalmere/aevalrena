# Sheet crops into the game (wave 2)

Inputs: `art/aeval/sheets/crops/*.png` + `crops/manifest.json` (from
`tools/sheetcut/cut.py`) and the lead-owned mapping `art/aeval/sheetmap.json`.
Output: Aeval draws from the crops in the running game.

## A. Atlas packer: `tools/sheetcut/pack.py`

1. Read `sheetmap.json` and `crops/manifest.json`.
2. Collect every crop name referenced by `body` anims (deduplicated) and every
   crop referenced by `fx`. Fail loudly (exit 1, list them) if a referenced
   crop PNG is missing.
3. Pack body crops into one PNG (shelf packing, 1 px gutter, width <= 2048)
   and fx crops into a second PNG.
4. Write `src/characters/aeval/art/atlas.body.ts` and `atlas.fx.ts`:
   ```ts
   // Generated by tools/sheetcut/pack.py. Do not edit.
   import type { ImageSheetData } from '../../../core/types';
   export const AEVAL_BODY_SHEET: ImageSheetData = {
     url: 'data:image/png;base64,....',
     origin: 'bottom-center',
     frames: { 'moves_idle_0': [x, y, w, h, ax, ay], ... },
   };
   ```
   The frame rect gains two optional trailing numbers `ax, ay`: the anchor
   inside the frame (from the manifest). Body anchors are the heel point; fx
   anchors are the crop centre.
5. Also write `src/characters/aeval/art/anims.ts` exporting
   `AEVAL_ANIMS: Record<AnimName, AnimDef>` (body) and
   `AEVAL_FX_ANIMS: Record<string, AnimDef>` built from sheetmap.json with
   `frames`, `holds`, `loop`, `mirror`, and `fps` = 60 / mean(holds) rounded
   (kept for anything still reading fps).
6. Print atlas sizes and the base64 byte counts. Each atlas must stay under
   1.5 MB of base64; if not, report it, do not shrink crops.

## B. Engine changes (TypeScript, `npm run typecheck` must pass)

1. `src/core/types.ts`
   - `ImageSheetData.frames` values become
     `[number, number, number, number] | [number, number, number, number, number, number]`
     (x, y, w, h, optional ax, ay). Document it.
   - `AnimDef` gains `holds?: number[]` and `mirror?: boolean`.
2. `src/render/bake.ts`
   - Store per-frame anchor with each baked frame entry. Default anchor when
     absent: `bottom-center` sheets use (w/2, h), `center` sheets use (w/2, h/2).
     For the flipped variant the anchor x becomes `w - ax`.
   - Export `getFrameAnchor(sheetId, frameName, flipped): {ax, ay} | null`
     (no allocation per call: return a reused object or two numbers via out
     params; pick one and keep the hot path allocation-free).
   - Outline rule: `isSolid` treats a pixel as solid only when alpha === 255.
     Water in the crops is capped at alpha 254 so the player-colour ring traces
     the body and skips the water. Update the comment on `outlineIgnore`.
3. `src/render/anim.ts`
   - `animFrameIndex`: when `def.holds` exists, walk the holds (loop with the
     total modulo, non-loop clamps to the last frame). Otherwise keep the fps
     path.
4. `src/render/fighters.ts`
   - Draw the body at `(x - ax, y - ay)` using the anchor, and flip when
     `facing === -1` XOR `def.mirror === true`. The outline canvas draws at
     the same offset minus 1.
   - Keep the placeholder path for a missing frame.
5. `src/render/fx.ts`
   - `drawCentered`: use the frame anchor when present instead of `w/2, h/2`.
   - Geyser/whirl block: unchanged (their frame lists will be empty and skip).
6. `src/render/hud.ts` portrait: unchanged unless it breaks; the portrait is
   `moves_idle_0` and may be taller than before, so clamp its draw height to
   the card (scale down with integer factor if needed).
7. `src/characters/aeval/sprites.ts`
   - Import the generated atlases and anims. `anims = AEVAL_ANIMS`.
   - Restore the `MOVE_ANIM` and `ACTION_ANIM` tables (they were in commit
     3164b9f: `git show 3164b9f:src/characters/aeval/sprites.ts`). Then add:
     `ledgeatk -> 'ledgeatk'`, `getupatk -> 'getupatk'`, `taunt2`, `taunt3`;
     actions `grab, grabHold, pummel, grabbed, tech, techRoll, downed, getUp,
     getUpRoll, footstooled` map to the anim of the same name;
     `throw` maps to `throwF` (the fighter state has no throw id; keep it
     simple); `finalSmash -> 'fsStart'`, `finalSmashVictim -> 'fsVictim'`.
   - Charge variants keep working through anim.ts's `Charge` suffix.
8. `src/characters/aeval/moves.ts`: `tidalCrescent.sprite` becomes
   `'crescent'`.
9. `docs/SPEC.md`: under the art/animation section, replace the 80x80 text
   frame paragraph with three lines: crops come from the four generated sheets
   in `art/aeval/sheets`, cut by `tools/sheetcut/cut.py`, packed by `pack.py`,
   mapped by `art/aeval/sheetmap.json`. Do not touch other sections.

## C. Gates (all must pass; report real exit codes)

1. `npm run typecheck` exit 0.
2. `npx --yes tsx src/render/rendertest.ts` exit 0 (fix anchor-related
   failures; if a test asserts the old placeholder box, update the assertion
   and say so).
3. `npm run test:sim` exit 0 (should be untouched).
4. Run `npm run dev`, open the game in the headless browser (the
   `browser-automation` skill), start a match against a CPU, take a
   screenshot after ~2 seconds and another after pressing an attack key.
   Save them to `art/aeval/sheets/crops/ingame1.png` and `ingame2.png`. The
   fighters must be the drawn character, not boxes, standing on the platform
   with heels on the floor line.
